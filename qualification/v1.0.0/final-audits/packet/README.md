# Additional packet soak audit

These are additional post-run observations from the completed Linux `live` and `reproduce` packet soaks. The audit finished on 2026-09-28 at 23:28:47 UTC. Each of the seven cases passed 212 times per command, with zero failures and spans of 7,223.394594 to 7,228.547123 seconds. The 2,968 CLI process passes each ran three repetitions, totaling 8,904 replay iterations. This does not establish that one CLI process stayed alive for two hours.

The audit independently checked the frozen source and Linux binary pins, rehashed all 17,818 unique retained artifacts (35,636 references across the two reports), checked 2,968 firewall snapshots, and observed removal of the owned namespaces, interfaces, and processes. The recorded-transcript validator accepted both complete reports. Stateful TCP ran with namespace-local delay, loss, and reordering. Transport TCP records request/transmission evidence without verified responses; wire observations do not change the CLI's unverified transmission-only result.

The authoritative release validator evidence remains the reports and transcripts referenced by the qualification manifest. This additional bundle does not change that manifest or replace those records. It covers Linux software peers in owned network namespaces and veth interfaces, not physical NICs, DUTs, or human pilots.
